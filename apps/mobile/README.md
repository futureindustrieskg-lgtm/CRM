# Мобильное приложение (Android / iOS)

React Native + Expo SDK 52, TypeScript. Отдельный пакет (не входит в npm workspaces корня),
чтобы зависимости React Native не смешивались с вебом и API.

## Что умеет (итерация 1 этапа 4)

| Роль | Вкладки |
|---|---|
| Студент | Главная (баланс, оплата долга, абонементы с остатком занятий, ближайшие занятия), Расписание (кнопка «Войти в урок» для онлайн-занятий), Успехи (оценки по навыкам, посещаемость), ДЗ (ответ текстом, фото тетради с камеры или из галереи, файл, голос до 5 минут; оценка и комментарий преподавателя; тесты с таймером), Сообщения, Профиль |
| Родитель | То же по каждому ребёнку (переключатель детей), без ДЗ; чат с администрацией филиала |
| Преподаватель | Занятия на сегодня / неделю, журнал: «Все пришли» → «Сохранить» (2 нажатия), отметки без интернета, тема из учебного плана; оценки по навыкам; перенос / отмена (или запрос администратору); чаты групп и личные со студентами |
| Сотрудники офиса | Чаты (обращения клиентов), уведомления, профиль; работа — в веб-версии |

**Чат:** группы, «студент — преподаватель», администрация филиала; текст, фото, файлы, голосовые.
Пока чат открыт, новые сообщения подгружаются каждые 5 секунд; о сообщениях при закрытом приложении
сообщает push, нажатие на него открывает переписку. Телефоны собеседников в чате не показываются.
У студента «Успехи» открываются кнопкой на главной (вкладок не больше шести).

- **Офлайн-отметки (сценарий S9).** Без связи отметка сохраняется на телефоне с временем устройства и уходит
  автоматически при появлении сети (или кнопкой «Отправить сейчас»). Сервер не даёт запоздавшей старой отметке
  затереть более позднюю. Журналы сегодняшних занятий загружаются заранее, чтобы их можно было открыть без интернета.
- **Без связи** экраны показывают последние загруженные данные с пометкой «Нет связи».
- **Push.** Телефон регистрируется на сервере (`POST /me/devices`); уведомления CRM дублируются push-ом через
  Expo Push Service (FCM / APNs). При выходе из приложения телефон отвязывается.
- **Безопасность.** Сессия хранится в Keychain / Keystore (expo-secure-store). Паспорт и контакты клиента в приложение не передаются.
- **ДЗ-тест.** Одна попытка; ответы сохраняются на телефоне после каждого выбора, поэтому закрытие приложения
  не обнуляет прогресс; по истечении таймера ответы отправляются автоматически.
- **Разрешения.** Камера, фото и микрофон запрашиваются только при первом использовании; тексты запросов —
  в `app.json` (плагины `expo-image-picker`, `expo-av`). Голос записывается в m4a (телефон) или webm (браузер).
- Языки: русский, кыргызский. Время занятий — по часовому поясу центра.

## Запуск для разработки

```powershell
cd apps/mobile
npm install
npx expo start
```

- Телефон: приложение **Expo Go**, сканировать QR. Адрес API — `extra.apiUrl` в `app.json`
  или переменная `EXPO_PUBLIC_API_URL` (для телефона в одной Wi-Fi сети — IP компьютера, например `http://192.168.1.10:3000/api/v1`).
- Эмулятор Android: `localhost` автоматически заменяется на `10.0.2.2`.
- Браузер (быстрая проверка экранов): `npx expo start --web` → http://localhost:8081
  (в `CORS_ORIGIN` API должен быть `http://localhost:8081`).

Демо-входы — те же, что в вебе: `asel@crm.test` (студентка), `parent@crm.test` (родитель), `teacher2@crm.test` (преподаватель).

## Сборка для телефонов и магазинов (EAS)

Сборки делаются в облаке EAS (Expo Application Services); Mac для iOS не нужен.
Профили — в `eas.json`:

| Профиль | Что получается | Для чего |
|---|---|---|
| `preview` | Android APK для установки по ссылке | проверка на телефонах сотрудников и пилотной группы, push работает |
| `production` | AAB (Google Play) и IPA (App Store / TestFlight), номер сборки растёт автоматически | публикация |

Адрес API задаётся в профиле (`EXPO_PUBLIC_API_URL` в `eas.json`): сейчас стоят заглушки `staging.example.com`
и `crm.example.com` — **замените на адрес вашего сервера (HTTPS)** до первой сборки.

### Шаг 1. Аккаунт и проект (один раз)

```powershell
cd apps/mobile
npx eas-cli@latest login
```

```powershell
npx eas-cli@latest init
```

`init` создаёт проект в Expo и записывает `extra.eas.projectId` в `app.json` — этот файл нужно закоммитить.
Пароль вводите сами; токены и ключи в репозиторий не кладутся.

### Шаг 2. Тестовая сборка Android (без Google Play)

```powershell
npx eas-cli@latest build --profile preview --platform android
```

Через 10–20 минут EAS даёт ссылку и QR-код на APK — его можно поставить на любой Android-телефон.

### Шаг 3. Push-уведомления

- **Android:** проект в Firebase → приложение с пакетом `kg.deutschzentrum.crm` → ключ сервисного аккаунта
  (JSON) → `npx eas-cli@latest credentials` → Android → Push Notifications (FCM V1). Файл ключа хранится только у вас.
- **iOS:** при первой iOS-сборке EAS сам создаёт ключ APNs в вашем Apple Developer аккаунте (нужен вход в Apple ID).

### Шаг 4. Магазины

- **Google Play:** аккаунт разработчика ($25 один раз) → приложение `kg.deutschzentrum.crm` →
  `npx eas-cli@latest build --profile production --platform android --auto-submit` (дорожка `internal` — внутреннее тестирование).
- **App Store:** Apple Developer ($99 в год) → `npx eas-cli@latest build --profile production --platform ios --auto-submit`
  → TestFlight → отправка на проверку.

До публикации нужны (этап 2 «Дизайн»): иконка 1024×1024 (`icon` в `app.json`), экран загрузки (`splash`),
скриншоты и описание для магазинов, политика конфиденциальности (ссылка обязательна в обоих магазинах).
Идентификатор `kg.deutschzentrum.crm` после публикации не меняется — подтвердите его заранее.

### Обновление SDK

Проект на Expo SDK 52. `expo-av` (запись и воспроизведение голоса) в новых SDK заменён на `expo-audio`:
при переходе на SDK 53+ модуль `src/media.tsx` нужно перевести на `expo-audio` (expo-doctor об этом предупреждает).

Push проверяется на реальном телефоне (на эмуляторе и в веб-версии недоступен).
