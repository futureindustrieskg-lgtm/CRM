# CRM учебного центра немецкого языка

Единая CRM: веб-кабинет для сотрудников и мобильное приложение (Android/iOS) на одном REST API.
Техническое задание — файл `ТЗ CRM для учебного центра немецкого языка (веб + Android iOS).docx`.

| Часть | Технологии | Папка |
|---|---|---|
| Сервер / API | Node.js, NestJS, Prisma, PostgreSQL | [apps/api](apps/api) |
| Веб-кабинет | React, Vite, TanStack Query | [apps/web](apps/web) |
| Мобильное приложение | React Native (этап 4) | `apps/mobile` — будет добавлено |

## Что уже работает (каркас этапа 3)
- Вход по e-mail/телефону и паролю, JWT + обновление сессии.
- Роли и права по модулям (чтение/создание/изменение/удаление/экспорт), редактирование из интерфейса.
- Несколько ролей у одного сотрудника, переключение без повторного входа.
- Ограничение данных по филиалу на уровне API; менеджер видит только свои лиды.
- Журнал действий (до/после, причина).
- Лиды: воронка канбан/список с перетаскиванием, карточка, история, задачи, контроль первого касания (15 мин),
  проверка дублей и объединение, отказ только с причиной, UTM-метки, перевод в студенты.
- Приём заявок с сайта: `POST /api/v1/webhooks/site-lead` (заголовок `X-Webhook-Token`).
- Студенты: список с фильтрами (статус, уровень, филиал, должники), карточка, согласие на ПД.
- Дашборд: воронка, лиды, конверсия, студенты, должники, выручка.
- Курсы (уровень, формат, часы, учебник, цена) и кабинеты филиалов.
- Группы: преподаватель, кабинет, минимум/максимум, даты, статус; зачисление, лист ожидания с автоматическим
  переводом в основной состав, перевод в другую группу с причиной, массовый перевод на следующий уровень;
  задача администратору филиала при наборе минимума.
- Расписание: календарь на день/неделю/месяц с фильтрами по филиалу, кабинету, преподавателю и группе;
  создание занятий по шаблону (например, пн/ср/пт 19:00–20:30) на весь курс с пропуском праздников;
  контроль конфликтов (преподаватель, кабинет, студент); перенос, замена преподавателя и отмена — с причиной в журнале.
  Время — по часовому поясу филиала. Преподаватель видит только свои группы и занятия.
- Интерфейс на русском и кыргызском (частично немецкий и английский), адаптивная вёрстка от 360 px.

## Запуск для разработки (Windows)

Нужны Node.js 22+ и PostgreSQL 17.

```powershell
npm install
copy apps\api\.env.example apps\api\.env   # заполнить DATABASE_URL, JWT_SECRET, WEBHOOK_TOKEN
npm run db:migrate                          # создать таблицы
npm run db:seed                             # демо-данные (учётные записи — в apps/api/prisma/seed.ts)
npm run dev:api                             # API: http://localhost:3000/api/v1, Swagger: /api/docs
npm run dev:web                             # Веб: http://localhost:5173
```
