### Порядок работ этапа 3 (итерации по 1–2 недели)
1. ✅ Каркас: вход, роли и права из интерфейса, филиалы, журнал действий.
2. ✅ Лиды: воронка (канбан), карточка, лента, задачи, проверка дублей, отказ с причиной.
3. ✅ Студенты: карточка, фильтры, перевод лида в студента.
4. Курсы, группы, лист ожидания; расписание с шаблонами и контролем конфликтов.
5. Посещаемость, списание занятий, оценки по навыкам, правило «2 пропуска подряд».
6. Финансы: прайс, абонементы, оплаты, задолженность, расчёт оплаты преподавателей.
7. ДЗ и тесты, входной тест уровня по ссылке.
8. Уведомления и шаблоны (push, WhatsApp, Telegram, SMS, e-mail), внутренний чат.
9. Документы PDF, отчёты и дашборд директора, выгрузка Excel/PDF.
10. Интеграции MVP: webhook сайта, WhatsApp, Telegram, SMS, эквайринг/QR, ЭКМ, Zoom/Meet, FCM.

## 3.2. Сценарии приёмки (черновик)

| № | Сценарий | Роли |
|---|---|---|
| S1 | Заявка с сайта (webhook с UTM) → лид в «Новая заявка» → назначен менеджер → задача «первое касание за 15 мин» | система, менеджер |
| S2 | Менеджер звонит → «Контакт установлен» → отправляет тест уровня → результат в карточке → «Тест уровня» | менеджер, лид |
| S3 | Запись на пробный урок → «Пробный урок» → договор → оплата в приложении → «Зачислен в группу» | менеджер, студент |
| S4 | Отказ: перевод в «Отказ» без причины невозможен; с причиной — попадает в отчёт причин отказов | менеджер |
| S5 | Повторная заявка с тем же телефоном → система предлагает объединение карточек | менеджер |
| S6 | Администратор создаёт роль «Методист» с правами только на чтение студентов и групп — без программиста | директор |
| S7 | Пользователь с ролями «администратор» и «преподаватель» переключается между ними без повторного входа | администратор |
| S8 | Менеджер филиала А не видит лиды и студентов филиала Б (проверка через API) | менеджер |
| S9 | Преподаватель отмечает посещаемость с телефона в 2 нажатия без интернета; после появления связи данные на сервере | преподаватель |
| S10 | Удаление оплаты без причины невозможно; с причиной — запись в журнале действий | бухгалтер |

Каждый сценарий проверяется в вебе, на Android и iOS.
