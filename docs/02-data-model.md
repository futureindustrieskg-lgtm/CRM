# 2. Модель данных

Источник истины — [apps/api/prisma/schema.prisma](../apps/api/prisma/schema.prisma). Ниже — смысл сущностей.

## Организация и доступ
| Сущность | Назначение |
|---|---|
| `Branch` | Филиал: название, адрес, часовой пояс (по умолчанию Asia/Bishkek) |
| `Room` | Кабинет филиала или онлайн-комната, вместимость |
| `User` | Учётная запись: e-mail и/или телефон, пароль (хеш), язык интерфейса |
| `Role` | Роль с массивом прав `модуль.действие`; системные роли не удаляются |
| `UserRole` | Роль пользователя в филиале; несколько ролей на одного человека |
| `RefreshToken` | Отзываемые токены входа (хранится только хеш) |
| `AuditLog` | Журнал изменений: до/после, причина |

## Продажи (3.1)
| Сущность | Назначение |
|---|---|
| `PipelineStage` | Настраиваемый этап воронки; `isWon` — «Зачислен», `isLost` — «Отказ» |
| `Lead` | Обращение: контакты, источник, UTM, уровень, цель, ответственный менеджер, результат теста уровня |
| `LeadActivity` | Лента карточки: комментарии, звонки, сообщения, смены этапа |
| `Task` | Задача менеджеру со сроком (перезвонить, подтвердить пробный урок) |

Правила:
- Дубли ищутся по телефону (нормализованному до цифр) и e-mail; при объединении у поглощённого лида
  заполняется `mergedIntoId`, лента переносится.
- Перевод в этап `isLost` невозможен без `lostReason`.
- `firstContactAt` фиксирует первое касание — для контроля срока 15 минут.

## Студенты (3.2)
| Сущность | Назначение |
|---|---|
| `Student` | Карточка студента: уровень, цель, статус, баланс, согласие на ПД |
| `ParentStudent` | Связка родитель (User) — ребёнок; плательщик |

## Обучение (3.3–3.6)
`Course` → `Group` → `GroupStudent` (в т. ч. лист ожидания) → `Lesson` → `Attendance`;
`Grade` — оценки по навыкам Hören / Lesen / Schreiben / Sprechen; `Homework` / `HomeworkSubmission`.

## Финансы (3.7)
`Payment` — оплата в сомах (KGS) с мягким удалением: `deletedAt` + обязательная `deleteReason`.
Абонементы, скидки, счета, ставки преподавателей добавляются в этапе 3.

## Справочники-константы
- Уровни: `A1, A2, B1, B2, C1, C2` (подуровни курсов `A1.1`, `A1.2` …).
- Цели: `exam`, `work`, `study`, `family`, `other`.
- Источники лида: `site`, `whatsapp`, `telegram`, `instagram`, `call`, `referral`, `manual`.
- Статусы студента: `active`, `paused`, `finished`, `left`.
